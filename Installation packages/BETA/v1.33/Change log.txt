Change log
2 May 2025

Added features
- turbine lube oil (tank heater, cooling loop, lube pump, turning gear)
- Turbine CTRL oil
- Turbine gland steam system
- Turbine metal temperature

Changes
- Primary coolant heating when in mode 5 or mode 4 is slowed down further. 12 minutes to 100 deg C and 12-20 minutes to design P and T
- RCP spin up/down slower - 2x
- Turbine - prep - heating lube oil, starting lube oil, jacking oil, turning gear
- seal steam manual start

Bug fix
- RHR cooling after shutdown - check CW in service and heaters off then should cool at accelerated rate



16 April 2025

Added features
- turbine Hot start/Cold start run up sequence added. 

Changes
- control rod visual representation on screen now moves in 1% increments (previously it was in 10% steps).
- Steam generator draining rate has been reduced.
- Pressuriser draining/filling rate also reduced.
- turbine cold start runup rate reduced (i.e. it now takes longer to reach syncronise speed).
- Primary coolant heating when in mode 5 or mode 4 is slowed down.

Bug fix
